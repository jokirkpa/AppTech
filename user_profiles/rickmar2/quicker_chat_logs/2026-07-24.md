**Quicker AI:** The `ping` command is a network diagnostic tool used to test connectivity between devices on a network. It sends Internet Control Message Protocol (ICMP) Echo Request packets to a target device and waits for an Echo Reply. This helps verify if the target device is reachable and measures the round-trip time of packets.

Basic syntax in Cisco IOS:

```
Router# ping <destination_IP_or_hostname>
```

For example:
```
Router# ping 8.8.8.8
```

This sends ICMP packets to Google's public DNS server (8.8.8.8).

You can also use extended ping for more advanced options by typing `ping` and pressing Enter, which allows you to configure parameters like packet size, timeout, and the number of pings. Let me know if you'd like details on extended ping!
