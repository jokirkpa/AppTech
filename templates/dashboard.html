❓ TCPDUMP Parameters Help

Common Parameters

-i [interface]
Specify network interface to capture from (e.g., eth0, en0)
-v, -vv, -vvv
Increase verbosity level (more v's = more details)
-c [count]
Capture only specified number of packets then exit
-w [filename]
Write raw packets to file (can be read with -r or Wireshark)
-n
Don't resolve IP addresses to hostnames
-nn
Don't resolve IP addresses or port numbers
-s [snaplen]
Set snapshot length (0 = capture full packet, default varies)
-A
Print packet payload in ASCII
-X
Print packet payload in hex and ASCII

Common Filters

host [address]
Capture traffic to or from specified address (IP or MAC)
src [address] / dst [address]
Capture traffic from source or to destination (IP or MAC)
port [number]
Capture traffic on specified port (src or dst)
tcp / udp / icmp
Filter by protocol type
net [CIDR]
Capture traffic to/from network (e.g., 192.168.1.0/24)
💡 Tip
Filters are combined with AND logic. Multiple filters will narrow down your capture.
